Five rings around the record

The model only asks. Every tool call has to cross five independent layers to reach the evidence, and a person decides anything that would change the record. Each ring is tagged with the rules it enforces (R1 to R9) and with how that was checked.

OUTSIDE THE PERIMETER

The model and its prompt

Claude Sonnet 4.6, temperature 0. The system prompt states the nine rules in plain language; it shapes what the model tries and is not counted as a control.

KNOWN GAP

The content rule is a word list

In the no-model run, a carefully worded accusation with none of the blocked words passed every layer and was stored as a finding live, T22

Contained, not prevented: a finding changes nothing in the record, and a person decides what it's worth.

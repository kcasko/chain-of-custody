Tool Lambda: the domain core

  • Deny by default; the agent gets 4 operations: read metadata, read originals, record a finding, draft a proposal
  • Closed schemas; exact versions only; a content rule refuses guilt, intent or blame
  • Identity and case from deployment configuration, never arguments; approvals and exports are human-only
  • Evidence returned with content_is_untrusted_data: true; times returned raw
  • Every backend decision, refusals included, goes to a durable append-only audit log

What an attack has to get past

  1. The harness tool allowlist
  2. Cedar at the Gateway
  3. The domain core's own checks
  4. IAM on the Lambda's role
  5. Create-only storage and the hash chain
  6. A person, for anything that changes the record

## Verified facts this plan relies on (checked November 18)

- Credentials resolve to an assumed role. OpenAI models are listed in us-east-1.
- CDK is **not** bootstrapped in us-east-1. The example session role `BedrockManagedAgentsPreviewInferenceServiceRole` does **not** exist.
- WSL Ubuntu (x86_64) has Codex CLI 0.157.1 (the docs require 0.154.0 or later), jq, curl 8.5 (SigV4 support) and Node 20.19. **AWS CLI v2 is not installed in WSL.** The bundle scripts need `aws configure export-credentials`.
- The Windows Codex CLI is 0.153.3, too old for exec-server. Self-hosted runs from WSL, which the docs support (Linux x86-64).
- Existing budgets: an account-wide $180/month budget (eg-v2), a $35 ByteGeist budget, and a tag-scoped $10 storm-signal budget. Month-to-date account spend is $17.19. None of them would catch a spike of this size quickly.
- **GPT-5.6 Luna is billed as AWS Marketplace software usage.** Cost Explorer shows it under "OpenAI GPT-5.6 Luna (Amazon Bedrock Edition)", not under "Amazon Bedrock". A budget filtered only to Amazon Bedrock would miss it.

Operating rules for the spike:
- Hard cap: **60 agent turns** total. Log the count.
- `maxTokens`-style output limits where the API exposes them. One turn at a time.
- No VPC mode, no NAT gateway, and **do not deploy the bundle's `acr/` stack** (it creates a NAT gateway, about $33/month in hourly charges alone).
- Synthetic data only. No real evidence, no credentials in instructions, skills or MCP env values.

## Cost estimate

Computed by script (Price List API and published AgentCore pricing, November 18, 2026). GPT-5.6 Luna us-east-1 regional standard: $0.22 per 1M input tokens, $0.022 per 1M cached input tokens, $1.32 per 1M output tokens.

| Line | Typical | Worst case | Assumption |
|---|---|---|---|
| Model inference, 60 turns | $0.43 | $2.38 | Typical 40k input (70% cached) + 3k output per turn. Worst 120k uncached + 10k output |
| AgentCore Runtime | $0.08 | $6.94 | Typical 3 session-hours, light CPU. Worst 4 sessions left to the 8 h max lifetime at 2 vCPU / 4 GB pegged |
| Gateway + Policy, 1,000 calls each | $0.03 | $0.03 | Published per-call prices |
| ECR, KMS, CloudWatch, CodeBuild, Lambda, S3 | $2.40 | $2.40 | Upper bounds; the CodeBuild ARM rate is unverified |
| **Total** | **about $3** | **about $12** | Under the $15 budget even in the worst case |

Not included, and excluded by design: NAT gateway (about $33 per month in hourly charges alone), VPC endpoints, Transaction Search.
